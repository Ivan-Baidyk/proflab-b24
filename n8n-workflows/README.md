# Рабочие процессы n8n (ПрофЛаб)

Экспорт всех боевых процессов автоматизации формирования КП. Каждый файл — готовый workflow n8n, который можно импортировать (в n8n: **Workflows → Import from File**).

> ⚠️ Секреты вычищены: ключи вебхуков Bitrix24 заменены на `YOUR_B24_WEBHOOK_KEY`, IP сервера — на `YOUR_SERVER_IP`, идентификаторы учётных записей (credentials) — на `YOUR_*_CRED_ID`. Перед запуском подставьте реальные значения и свои credentials PostgreSQL/DeepSeek.

## Общая схема

```text
        ┌─────────────────────────── ВИДЖЕТ (Bitrix24) ───────────────────────────┐
        │   вкладка сделки → поиск позиций → список → кнопка «Сформировать КП»    │
        └───────┬─────────────────────────┬──────────────────────────┬───────────┘
                │ поиск                    │ загрузка КП              │ создание КП
                ▼                          ▼                          ▼
        01 Поиск позиций            07 Загрузка КП              05 Создание КП ──┐
                                                                                 │
    ┌─ 02 Обработка прайс-листа (наполнение каталога) ─┐                          │
    │     └─ 03 Обработка позиций (вспомогательный)     │                          │
    └──────────────────────────────────────────────────┘                          │
    08 Единицы измерения (справочник для выпадающих списков)                       │
    04 HTML → PDF (конвертер, используется в 05)  ◄───────────────────────────────┘
    06 Ошибка процесса (мониторинг сбоев — создаёт задачу в Б24)
```

## 01. Поиск позиций

**Зачем.** Обслуживает поле автоподбора в виджете: когда менеджер вводит текст, система на лету подсказывает подходящие товары из каталога.

**Как работает.**
1. Принимает POST с параметром поиска `q` (что ввёл менеджер).
2. Очищает запрос от служебных символов (защита от некорректного ввода).
3. Ищет в таблице каталога `Прайсы` совпадения по полю «Наименование» (поиск по части строки).
4. Возвращает до 20 подходящих позиций: наименование, единица измерения, артикул, оптовая цена, валюта.

**Результат.** Выпадающий список подсказок в виджете.

---

## 02. Обработка прайс-листа

**Зачем.** Наполняет каталог данными и держит справочники в актуальном состоянии.

**Как работает.**
1. **Через форму** менеджер/администратор загружает файл прайс-листа поставщика (XLS).
2. По имени файла определяется поставщик (он должен быть указан в скобках в названии).
3. Файл разбирается: проверяется структура (заголовки), извлекаются позиции, определяется категория каждой.
4. Старые позиции этого поставщика удаляются, новые записываются в каталог `Прайсы`.
5. **По расписанию (раз в час)** запрашиваются курсы валют с сайта Центробанка (евро, доллар, юань) и записываются в таблицу `курсы_валют`.
6. При первом запуске автоматически создаются нужные служебные таблицы.

**Результат.** Актуальный каталог товаров и свежие курсы валют.

## 03. Обработка позиций каталога (вспомогательный)

**Зачем.** Внутренний подпроцесс, который вызывается из «Обработки прайс-листа» для разбора отдельных позиций.

**Как работает.** Запускается автоматически (не по вебхуку), получает на вход подготовленные строки каталога и обрабатывает их по одной. Отдельно он не запускается — это часть конвейера загрузки прайс-листа.

## 04. HTML → PDF (Gotenberg)

**Зачем.** Превращает готовую HTML-разметку документа в PDF-файл.

**Как работает.**
1. Принимает POST с HTML-разметкой и именем файла.
2. Передаёт HTML в сервис `html2pdf-api`, который через **Gotenberg** (Headless-браузер) отрисовывает страницу и «печатает» её в PDF.
3. Возвращает ссылку на готовый PDF-файл.

**Результат.** Публичная ссылка на PDF, которую можно открыть или отправить клиенту.

---

## 05. Создание КП (главный процесс)

**Зачем.** Полный цикл формирования коммерческого предложения — от данных из виджета до готового PDF и записи ссылки в сделку.

**Как работает (по шагам).**
1. Принимает от виджета: ID сделки и список позиций (наименование, количество, выбранная единица измерения).
2. По каждой позиции запрашивает полные данные из каталога (по артикулу и наименованию).
3. С помощью AI-агента (DeepSeek) обрабатывает/уточняет данные позиции.
4. Подтягивает вспомогательные данные: базовую наценку, курсы валют, правила перевода единиц.
5. Сохраняет КП в базу данных `Готовые КП` (старую версию по сделке заменяет актуальной).
6. Запрашивает из Bitrix24: данные сделки, ответственного менеджера, компанию и её адрес.
7. Формирует итоговый HTML-документ (внешний вид коммерческого предложения).
8. Отправляет HTML на конвертацию (процесс 04) и получает PDF.
9. Возвращает ссылку на PDF обратно в Bitrix24 — она записывается в карточку сделки.

**Результат.** Сформированное КП: сохранено в базе, PDF создан, ссылка доступна в сделке.

## 06. Ошибка процесса

**Зачем.** Мониторинг: если какой-то процесс падает с ошибкой, об этом сразу узнаёт ответственный.

**Как работает.**
1. Перехватывает ошибку любого из процессов ПрофЛаб (Error Trigger).
2. Формирует срок (например, +1 час).
3. Создаёт в Bitrix24 задачу «Ошибка в процессе» со ссылкой на упавший запуск — чтобы можно было быстро открыть и разобраться.

**Результат.** Ни одна ошибка не остаётся незамеченной; её видно в Bitrix24 как задачу.

## 07. Загрузка КП для виджета

**Зачем.** При открытии вкладки виджет спрашивает: «есть ли уже готовое КП по этой сделке?» — чтобы менеджер мог отредактировать прежний состав, а не набирать заново.

**Как работает.**
1. Принимает ID сделки.
2. Находит в таблице `Готовые КП` все позиции этой сделки.
3. Возвращает список позиций: наименование, количество, выбранную единицу измерения, артикул, цену, валюту.

**Результат.** Готовое КП подгружается в виджет для редактирования.

---

## 08. Единицы измерения

**Зачем.** Справочник для выпадающих списков в виджете: показывает, какие альтернативные единицы есть у стандартной (например, для «кг» — «г» и «мг»).

**Как работает.**
1. Принимает GET-запрос.
2. Возвращает все активные правила перевода из таблицы `перевод_единиц_измерения`: какая единица в прайсе, какая в запросе, операция (умножить/разделить) и коэффициент.

**Результат.** У позиций в виджете появляется выпадающий список выбора единицы измерения (только там, где есть альтернативы).
